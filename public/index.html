แนวทางการทำงานของระบบ

1

ผู้ใช้ส่งลิงก์

วางลิงก์สินค้า Shopee หรือ Lazada ลงในช่องด้านบน ระบบตรวจสอบแพลตฟอร์มและดึง itemId ออกมา

2

แปลงลิงก์ (URL Converter)

เรียก Shopee Affiliate GraphQL generateShortLink เพื่อเปลี่ยนลิงก์ธรรมดาเป็นลิงก์ที่ผูก SubID ฝั่ง Lazada ใช้เทมเพลต affiliate ที่ตั้งค่าไว้ (รองรับ API ของคุณเอง)

3

แสดงผลเปรียบเทียบ

แสดงปุ่ม “สั่งซื้อที่ Shopee” / “สั่งซื้อที่ Lazada” ที่ผูก affiliate แล้ว พร้อมบอกว่าที่ไหนถูกกว่ากี่บาท และแยกหมวดหมู่สินค้าชัดเจน
